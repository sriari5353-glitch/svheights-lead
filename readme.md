This repository is a specialized real estate lead management and CRM platform designed to streamline property sales pipelines.
Originally developed for the SV Heights venture, the system has evolved into a complete digital ecosystem hosted under the custom domain anyacrm site.
The architecture integrates frontend development on Lovable dev with a robust Supabase backend for database management. A primary feature of the platform is its automated lead capture, ingesting prospective buyer data directly from Meta advertising campaigns. To facilitate immediate follow up, the dashboard includes built in WhatsApp and direct calling tools.
Security and operational integrity are maintained through strict role based access control, separating administrative privileges from standard user access. By unifying lead generation, CRM management, and custom branding into a singular workflow, this project provides a scalable foundation for modernizing real estate digital architecture.
